Nwagra (Nwagyu)

Par défaut, le site NumWorks n’autorise qu’environ 2,5 Mo d’applis externes. Nwagra fait croire à l’installateur qu’il peut aller jusqu’à environ 6 Mo (en réutilisant la copie de secours du système).

Sur les versions récentes d’Epsilon, Nwagra peut être incompatible (message « mode examen »). Dans ce cas, utilisez l’installateur lancer.bat avec nwlink plutôt que le site.

1. Glissez ce bouton dans la barre des favoris de Chrome :

Nwagra

  1. Mettez à jour la calculatrice sur le site NumWorks, deux fois (A/B).
  2. Débranchez-la, puis allez sur my.numworks.com/apps (Chrome).
  3. Cliquez le favori Nwagra : le titre devient « Enlarged Extra Apps ».
  4. Connectez, choisissez le .nwa puis la ROM / données, puis Installez.
